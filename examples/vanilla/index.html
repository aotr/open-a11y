Accessibility that fits the page, not the other way around.

Vanilla JS

This is the framework-free adapter. The widget is a set of web components, powered by the same engine used by every other demo. Change the controls below and the mounted widget updates live.

One engine, many surfaces

The engine owns accessibility state, profiles, persistence, and tool effects. The floating button and sidebar are web components, so they work in plain HTML without a build-time framework.

  • Keyboard shortcuts: Alt+A open, Alt+R reset, Escape close.
  • Profiles and individual tools share canonical state.
  • Settings persist in localStorage.
