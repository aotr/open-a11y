# 🌐 Internationalization (i18n) — Translation System

> `src/i18n/`

The i18n system provides multi-language support for the accessibility widget UI. Currently supports 10 bundled UI languages: English, Hindi, Bengali, Marathi, Tamil, Telugu, Gujarati, Kannada, Malayalam, and Punjabi. The architecture is ready for more.

---

## 🏗️ Architecture

```
┌─────────────────────┐
│ languages.ts         │  One locale table (metadata + dictionary)
│ LOCALES              │
│ LANGUAGES[]          │  Derived from LOCALES
│ LANGUAGE_CODES[]     │  Derived from LANGUAGES
│ loadTranslations()   │
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│ translator.ts        │  Runtime translation engine
│ initTranslations()   │  Load locale JSON, replace placeholders
│ translate()          │  Look up key, return translated string
│ translateWith()      │  Curried translate for a specific locale
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│ locales/             │  Translation dictionaries (JSON)
│   en.json            │  English (base language)
│   hi.json            │  Hindi
│   bn.json            │  Bengali
│   mr.json ... pa.json│  Marathi, Tamil, Telugu, Gujarati, Kannada, Malayalam, Punjabi
│   (fr.json, ...)     │  Extensible — just add JSON
└─────────────────────┘
```

## 📋 Language Registry (`languages.ts`)

`LOCALES` is the only table to edit when adding a language: it holds metadata
and the bundled dictionary. `LANGUAGES` and `LANGUAGE_CODES` are derived from it.
The core and React entries share this module at runtime; the React build imports
`dist/index.js` instead of bundling a second copy.

```ts
export interface ILanguage {
  code: string; // ISO 639-1 ('en', 'hi', 'bn', 'mr', 'ta', 'te', 'gu', 'kn', 'ml', 'pa')
  label: string; // Display name in English ('বাংলা (Bengali)')
  nativeLabel: string; // Display name in native script ('বাংলা')
}

export const LANGUAGES: ILanguage[] = [
  { code: "en", label: "English", nativeLabel: "English" },
  { code: "hi", label: "हिन्दी (Hindi)", nativeLabel: "हिन्दी" },
  { code: "bn", label: "বাংলা (Bengali)", nativeLabel: "বাংলা" },
  { code: "mr", label: "मराठी (Marathi)", nativeLabel: "मराठी" },
  { code: "ta", label: "தமிழ் (Tamil)", nativeLabel: "தமிழ்" },
  { code: "te", label: "తెలుగు (Telugu)", nativeLabel: "తెలుగు" },
  { code: "gu", label: "ગુજરાતી (Gujarati)", nativeLabel: "ગુજરાતી" },
  { code: "kn", label: "ಕನ್ನಡ (Kannada)", nativeLabel: "ಕನ್ನಡ" },
  { code: "ml", label: "മലയാളം (Malayalam)", nativeLabel: "മലയാളം" },
  { code: "pa", label: "ਪੰਜਾਬੀ (Punjabi)", nativeLabel: "ਪੰਜਾਬੀ" },
];
```

**Adding a new language:**

1. Create `locales/fr.json` (or equivalent)
2. Add it to `LOCALES` in `languages.ts`
3. That's it — the UI auto-populates the language dropdown

## 🔤 Translation Engine (`translator.ts`)

### Loading Translations

```ts
export async function initTranslations(locale: string): Promise<void> {
  if (TRANSLATION_DICTIONARY[locale]) return; // Already loaded

  const data = await loadTranslations(locale);
  TRANSLATION_DICTIONARY[locale] = data;
}
```

Called once at engine startup. Translations are cached in `TRANSLATION_DICTIONARY` to avoid re-fetching.

### Looking Up Translations

```ts
export function translate(key: string, lang?: string): string {
  const locale = lang ?? getDefaultLanguage();
  const dict = TRANSLATION_DICTIONARY[locale];

  // Walk the dot-notation key: 'tools.fontSize' → dict.tools.fontSize
  const keys = key.split(".");
  let value: any = dict;
  for (const k of keys) {
    value = value?.[k];
  }
  return typeof value === "string" ? value : key; // Fallback to key
}
```

**Dot notation:** `translate('profiles.visionImpaired', 'hi')` → looks up `dict.profiles.visionImpaired`

**Fallback:** If a key doesn't exist in the target language, returns the key itself. No crash, no blank UI.

### Curried Translator

```ts
export const translateWith = (lang: string) => (key: string) => translate(key, lang);

// Usage:
const t = translateWith("hi");
t("tools.fontSize"); // → 'फ़ॉन्ट आकार'
```

## 🔄 UI Update Flow

```
User clicks language toggle (EN → हि)
  → menu dispatches asw:language event { lang: 'hi' }
    → wire-up.ts calls engine.setLanguage('hi')
      → engine calls the internal StateManager.setLanguage('hi')
      → engine calls initTranslations('hi') → loads hi.json
      → menu.setLang('hi') + menu.translateUI()
        → All [data-translate] elements are re-rendered with Hindi text
```

**UI rendering:** The menu template uses `data-translate` attributes:

```html
<button data-translate="tools.fontSize">Font Size</button>
```

The `translateUI()` method walks all `[data-translate]` elements and replaces their text content with the translated string.

## ➕ Adding a New Language

1. Create `src/i18n/locales/fr.json` with the same structure as `en.json`
2. Add it to `LOCALES` in `languages.ts`:

```ts
fr: {
  label: "Français (French)",
  nativeLabel: "Français",
  dictionary: fr as Record<string, unknown>,
},
```

3. Done — no code changes needed. The language dropdown auto-populates.
